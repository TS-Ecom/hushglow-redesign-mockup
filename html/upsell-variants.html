Upsell row — four treatments

Sasha’s note was that the upsells are too big. All four below carry the same three products and the same offer; what changes is how much height one row is allowed to take and what the customer taps. Heights are measured live, on this page, at the width shown. Switch to desktop to check that nothing is lost on a wide screen.

TodayWhat is on the site now

Photo and copy on the first line, a full-width button on the second. The description is shown on the phone as well as the desktop.

Option 1One row, description on desktop only

Everything on one line: photo, name, price, button. The description comes back on the desktop, where there is room for it. This is the split the block had originally, with the row tightened further.

Option 2Toggle row, same as the travel puff

The same shape the Premium Travel Puff already uses further up the same page, so the buy box speaks one language instead of two. The switch reads as on or off rather than as a button whose label has to change once it is pressed.

Option 3Two lines kept, but slim

Closest to today. The description stays on the phone but is held to one line, the photo drops to 72px and the button gets a shorter one. Use this if the description is doing work we do not want to lose.
